# Event searcher  
Проект разрабатывался весной 2026 года на зачёт по дисциплине "Web-программирование", 3 курс.  
Стек:
- Fronted: HTML+Jinja, CSS+Bootstrap, JS
- Backend: Python, Django, MySQL  

Проект демонстрирует присутствующие навыки на момент написания.

Для запуска приложен дамп БД, в файле `/main/templates/event_create.html` в строке 87 необходимо вставить свой API ключ [сервиса Geocode](https://geocode.maps.co/)
